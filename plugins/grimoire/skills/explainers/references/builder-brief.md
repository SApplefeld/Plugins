# Builder Brief

Fill one copy per build in the build folder, and hand it to the builder as its prompt. A field with nothing to say reads `none`.

## Goal

What the watcher understands at the end, in one sentence.

## Deliverable

`video` or `diagram`, the build folder, and the output file name, with `draft` in it for a draft.

## Kit Root

The kit plugin root, as an absolute path.

## Paths

Each absolute path the session passed to the preflight with `--browser`, `--ffmpeg` or `--settings`, never a path it printed. For a diagram, the browser only where `render-html.js` named a missing browser and the session found one.

## Invented Names

Each made-up name the build uses, written once, as the picture and the narration both spell it.

## Spellings

Each settled spelling, the shown form for a scene's `text` and the sent form for its `spoken`. Each name new to the voice, marked `new`.

## Look

The look from the operator-tier style records.

## Scene

One block for each scene, in order:

- Title: a few words.
- Narration: the exact words spoken.
- Picture note: what must be seen, naming what arrives, travels or changes.

A diagram has one picture note and no narration.

## Report

Return:

- The file's path, and for a diagram the rendered image's path.
- The check's output and each contact sheet's path.
- Each scene's start against its narration's start.
- Each settled spelling with its last read-back line.
- The capture method, with its reason where it is not the kit's script.
- `not checked` for each check not run.
